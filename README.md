# BinaryGame — Learn Binary the Fun Way

> Master binary numbers before the clock runs out

An interactive browser game inspired by the Cisco binary game. Four modes, three difficulty levels, local high scores, and streak bonuses.

🔗 **Live:** https://binarygame-ryankorir00-4850s-projects.vercel.app *(deploy link pending)*

---

## Game Modes

| Mode | Description |
|---|---|
| **Classic** | A decimal number appears — flip bits to match it before time runs out |
| **Reverse** | A binary pattern is shown — type its decimal value |
| **IP Mode** | Convert each octet of a random IP address to binary |
| **Blitz** | 60 seconds, max score, no breaks |

## Scoring

- **+10 pts** per correct answer
- **+5 pts** per extra point for each answer in a streak
- **Time bonus** at the end — remaining seconds × 2

## Stack
Pure HTML · CSS · Vanilla JS · localStorage for high scores
